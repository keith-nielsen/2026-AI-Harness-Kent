TQ-40 HTTP API (firmware 3.4.x)

Base URL: http://<device>/. Authentication: header X-TQ-Token.

GET /v2/readings

Parameters: channel (1–4, required), since (ISO 8601, optional), limit (1–5000, default 500), cursor (optional).

Returns {"readings": [{"t": "...", "c": 21.37}], "next_cursor": "..."}. Temperatures are in degrees Celsius.

GET /v1/readings (deprecated)

Parameters: ch, n. No pagination; at most 1000 readings.

Rate limit

10 requests per second per token (firmware 3.4.2 and later); 5 per second before.
