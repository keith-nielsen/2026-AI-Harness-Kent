TQ-40 firmware release notes

3.4.2 — 2026-08-19 (current stable)

  • Fixes a Wi-Fi reconnect loop after DHCP lease renewal.
  • Raises the API rate limit from 5 to 10 requests per second.

3.4.1 — 2026-07-02

  • Fixes timestamps drifting by up to 2 s per day when the sample interval is under 1 s.

3.4.0 — 2026-05-27

  • Adds the /v2/readings endpoint with cursor pagination.
  • Deprecates /v1/readings (removal planned for 4.0).

3.3.5 — 2026-03-11

  • Security: fixes an unauthenticated firmware-upload path (HAL-2026-004). Upgrade strongly recommended.

3.3.4 — 2026-01-20

  • Battery estimate now accounts for cold-temperature capacity loss.

4.0.0-beta.2 — 2026-09-10 (beta, not for production)

  • Removes /v1/readings. Adds MQTT export.
